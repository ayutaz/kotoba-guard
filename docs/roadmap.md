## 完了した早期提供の順序

[v0.1.0公開記録](validation-v0.1.0.md)に実行結果を記録する。以下の1〜4は完了済み。

1. 実装済みの公開CLI/workflowをレビューし、関連テストを通す。
2. 公開ソースとZIPを固定し、再現性・SHA・SBOM・ライセンスを確認する。
3. 展開ZIPの実モデルE2Eと通信監査を実行する。
4. GitHub prereleaseへ同じZIPを公開し、ダウンロード後のSHAとタグを照合する。

初回はローカルCLIで公開する。以降は固定bundleをworkflowで検証・公開する。
Chrome Web Store初回申請・更新自動化は後続とする。[具体的な計画](next-steps.md)を参照。

速度・サイズ・長期メモリ最適化は後工程。旧100ms目標は達成扱いにしない。
精度目標や正式M5条件を無断で縮小しない。preview準備と正式公開を分ける。
P1はWebGPU UI/候補生成/辞書/70M、P2は他ブラウザ・npm/VS Code/textlint/CLI。
これらをZIP化の前提に増やさない。[具体的再開点](next-steps.md)を参照。

過去のM1〜M5計画と結果は各[研究記録](index.md#研究と過去の検証)および
`git show c14a591:docs/roadmap.md`に保持する。
